# BioLab · 细胞探索器

在 BioLab 生命探索平台中集成的交互式**细胞探索器**：可缩放、可点击的细胞结构图，
用于观察和对比**动物细胞、植物细胞、原核细胞**的基本结构。

## 功能

- **可缩放的细胞结构图**：滚轮缩放（以指针为中心）、拖拽平移、双击放大、工具栏按钮与缩放百分比显示。
- **点击查看细胞器详情**：点击图中的细胞器（或下方结构列表），侧栏展示其名称、英文名、主要功能、分布位置与相关知识。
- **功能关系图谱**：切换到“功能关系”视图，查看细胞器之间如何协作——
  - 有向连线表现 **信息流动**（转录、翻译）、**物质流动**（囊泡运输、呼吸底物）与 **能量流动**（捕获光能、氧化磷酸化）；
  - 内置 5 条**关系链**（中心法则、分泌蛋白的旅程、光合作用、有氧呼吸、能量的接力），选中后依次播放流动动画并标注步骤顺序；
  - 点击节点 / 连线查看对应的生物学解释，并可从任一节点继续跳转探索相关节点；
  - 图谱为**跨细胞类型的通用图谱**（明确标注，不随细胞切换而改变）；同时以当前细胞为视角，用虚线描边标出不存在于该细胞的细胞器；
  - 细胞器详情中的“功能关系”列表可一键跳进图谱，图谱中的细胞器节点也可跳回结构图（若需切换细胞，按钮会明确写出目标细胞）。
- **细胞类型切换**：动物 / 植物 / 原核细胞一键切换，直观呈现结构差异（细胞壁、叶绿体、中央大液泡、拟核、鞭毛……）。
- **生命过程动态模拟**（第三个视图「生命过程」）：三个数据驱动的动态过程——
  - **细胞分裂**：间期复制 → 前期凝缩 → 中期列队 → 后期分离 → 末期重建 → 胞质分裂；
  - **蛋白质合成与分泌**：基因激活 → 转录 mRNA → 核孔输出 → 核糖体翻译 → 内质网加工 → 高尔基体分拣 → 囊泡胞吐；
  - **物质跨膜运输**：O₂ 自由扩散、Na⁺ 通道 / 葡萄糖载体协助扩散、Na⁺/K⁺ 泵水解 ATP 的主动运输。
  - **不是预设视频**：每个过程由后端关键帧数据 + 前端插值引擎驱动——播放 / 暂停 / 调速（0.5×–4×）/ 循环 / 逐阶段暂停 / 拖动进度条 / 点击阶段导航，画面与状态指标（DNA 含量、染色体数、氨基酸数、ATP 消耗、各物质进出数……）在任意时刻都严格对应当前数据状态，并可回到任意阶段重新观察。
  - 关键步骤在画面浮层与侧栏显示当前生物学事件、详细解释和知识点；高亮结构可一键跳回结构图查看。
- **结构对比表**：三种细胞 × 全部结构的并集对照表（✓ / —）。
- **跨细胞跳转**：细胞器详情中的“出现于”芯片可直接切换到含有该结构的其他细胞并自动选中。
- 标签显隐切换、悬停提示、键盘可达（Tab + Enter）、移动端自适应。

## 架构

主要数据全部来自后端 API，前端只负责渲染：

```
GET /api/cells               细胞类型列表（含每种细胞的结构清单，用于切换与对比）
GET /api/cells/:id           某种细胞的完整结构图（每个细胞器的 SVG 图形描述 + 标签位置）
GET /api/organelles/:id      细胞器详情（名称 / 功能 / 位置 / 相关知识 / 出现于哪些细胞 / 参与的功能关系）
GET /api/relations           完整功能关系图谱：节点（细胞器 / 分子 / 能量 / 环境）+ 有向关系边 + 关系链
GET /api/relations/nodes/:id 单个关系节点详情：解释文案 + 与它相连的全部关系
GET /api/processes           生命过程列表（摘要：名称 / 适用细胞 / 步骤数 / 总时长）
GET /api/processes/:id       单个过程的完整模拟数据：步骤说明 + 实体关键帧轨道 + 状态指标
```

- **后端** `server/`：Express + better-sqlite3。细胞类型、细胞器、细胞结构三张表之外，
  另有 `relation_nodes`（图谱节点，含布局坐标）、`relation_edges`（有向关系，含过程解释）、
  `relation_chains` + `chain_edges`（关系链及其有序边）四张表承载关系数据；
  动态过程由 `processes` / `process_steps` / `process_entities`（每实体一条关键帧轨道）/
  `process_metrics`（每步结束时的状态值）四张表承载。种子数据在 `server/cellSeed.ts`、
  `server/relationSeed.ts` 与 `server/processSeed.ts`，首次启动自动建表灌入。
- **前端** `src/explorer/`：React 组件 —— `CellExplorer`（容器/状态/视图切换）、`CellCanvas`（SVG 渲染 +
  缩放平移）、`RelationGraph`（关系图谱：贝塞尔连线 + 箭头 + 流动动画）、`RelationPanel`（图谱侧栏：
  导览 / 节点解释 / 过程解释 / 关系链步骤）、`InfoPanel`（详情侧栏）、`CompareModal`（对比表）、
  `Shape`（图形描述 → SVG 元素）。
  动态过程部分：`ProcessExplorer`（过程容器）、`ProcessScene`（实体插值状态 → SVG 场景）、
  `ProcessControls`（播放/暂停/调速/进度拖拽/步骤导航）、`ProcessPanel`（事件浮层数据 + 实时指标 +
  阶段导航）、`useProcessPlayer`（rAF 虚拟时钟）、`processEngine`（纯函数：关键帧补全 / 时间采样 /
  数值与指标插值 / SVG 路径弧长采样）。关键帧只写“变化的属性”，引擎在帧间做缓动插值，
  因此暂停、调速、拖动到任意时刻，渲染的都是该时刻由数据计算出的确定状态。
- 页面入口：首页 Hero 按钮、顶部导航“细胞探索器”、细胞主题页 CTA，路由为 `#/explorer`（`#explorer` 与 `#/explorer` 两种写法均可解析）。

## 运行

```bash
npm install        # 如遇 better-sqlite3 编译问题：CC=gcc CXX=g++ npm install
npm run dev        # 同时启动 API（:8791）与前端（:5181）
```

打开 http://localhost:5181/#/explorer 即可进入细胞探索器。
